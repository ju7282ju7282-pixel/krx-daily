다. 판매전략 
(1) 정보 API 상품 판매를 통한 국내 사업 확대 -「쿠콘닷넷」을 통한 API 유통 - 판매채널 제휴를 통하여 시장 확장 - 핀테크 기업 육성으로 핀테크 기업과의 제휴 및 API 활성화 - 제휴 금융기관 API, 제휴 기관 API 유통을 통하여 시장 확장 데이터 3법 개정으로 마이데이터 사업이 활성화 됨에 따라, 당사는 새로운 API 시장의 선점을 위해 다양한 API를 제공하고 있습니다. 또한, 새로운 API 상품 발굴 및 서비스 품질 강화를 위한 R&D 투자와 함께, 제휴 채널을 통한 API 상품 판매를 확대하고 있습니다. 당사는 '21년 1월 금융위원회로부터 마이데이터업 본허가를 획득하였습니다. 이에 따라 마이데이터 관련 상품을 출시하고, 마이데이터 서비스가 2022년 1월부터 전면 시행됨에 따라 본격적으로 마이데이터 서비스를 오픈하여 관련 시장을 선점하고 있으며, 마이데이터 미인가 기관에 마이데이터 서비스를 제공하는 제휴 사업을 진행하고 있습니다. (2) 현지 법인을 통한 글로벌 정보 API 상품 판매로 글로벌 사업 확대 - 중국: 중국에 진출한 한국계 금융기관에 현지 금융 정보를 제공하는 사업 전개 - 일본: 일본 금융기관, 일반 기업, 핀테크 기업, ERP 기업 대상으로 시장 확대 - 캄보디아/베트남: 동남아시아 현지 자금 관리 상품을 활용하여 사업 전개
